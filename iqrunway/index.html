Method · how to read this

Separate the evidence

Score provenance

Site-reported subtest score means a number visibly returned by the assessment site for that subtest. Not scored — means no overall value was returned—not zero, failure, or an invitation to estimate.

Age application

Age 27 applied appears only when age 27 was actually entered on the site. Otherwise the board says target age 27 · not applied. A target is not evidence of application.

Completion

Every subtest keeps its own state: completed, stopped, blocked, or not started. One completed subtest does not become a completed battery.

Route and fallback

The requested model route and observed served route are shown separately. Fallback is reported from run attestation, never inferred from a display name.

Protocol time

Elapsed time is agent + browser protocol time for the stated scope. It is not isolated model latency, processing speed, clinical timing, or evidence about human intelligence.

Public boundary

The board stores metadata and outcome summaries only. Protected assessment content, raw browser state, screenshots, personal identifiers, private paths, and owner-private transcripts stay out.
